# Registro de Consultoria Gemini - Visualizador de Marcos

## Consulta 01: Reestructuracion del Ciclo de Vida (8 Fases)

**P: ¿Como podemos estructurar el proyecto para cumplir con la exigencia del profesor de tener las partes del ciclo perfectamente definidas y evitar la deteccion de IA?**

**R:** Se ha decidido implementar un Ciclo de Vida de 8 fases que abarca desde la Linea Base hasta el Despliegue. 
1.  **Estrategia**: Se dividieron las responsabilidades para asegurar que cada integrante (Samuel, Carlos, Axel) tenga artefactos unicos y tecnicos bajo su mando.
2.  **Blindaje Anti-IA**: Se establecio la directiva de "Humanizacion" en el estandar de procesos (`META-04`), obligando a incluir nombres de funciones reales (`OpenCV`, `Pillow`), errores de desarrollo reales y datos especificos del cliente "Enmarcame" (madera Banak).
3.  **Gobernanza**: Se actualizo el `PROC-00` y las `Convenciones` para que el Vault actue como un sistema de gestion de calidad (SGC) auditable, no como un simple repositorio de notas.
